# Brainz

A brain that lights up: four RGB LEDs shine through the translucent PCB artwork on the front.

<img src="manual/images/thumbnail.jpg" width=300px alt="Brainz">

- Difficulty: **2/5**

### Parts List

| Description                   | Quantity |
|-------------------------------|----------|
| RGB LEDs 5mm                  |     4    |
| Switch (Button)               |     1    |
| CR2032 Battery Holder         |     1    |
| CR2032 Battery (not included, available at distribution) | 1 |
| Brainz (PCB)                  |     1    |
| Pin / brooch pin (optional, at distribution) | 1 |
